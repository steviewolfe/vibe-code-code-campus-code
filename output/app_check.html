Reference

This report documents 8 primary user journeys covering landing, product browsing, authentication, informational pages, and chat interactions; plus cross-cutting tests for mobile responsiveness, design system consistency, and backend performance. Note: J7 and J8 are documented but lack captured screenshots (pending). Backend timings are referenced from earlier docs, not re-measured here.

Design System Verification

Reference
Campus Customs implements a bold, high-contrast design system inspired by pudding.cool, a digital publication known for striking data-driven visual design. The system uses a carefully curated color palette, thick borders for visual separation, hard offset shadows for depth, and consistent scaling across all components and responsive breakpoints. Note: This section documents design specifications without separate testing screenshots; visual verification occurs throughout J1–J8 journeys.

Color Palette

Token Value Usage
Primary Pink #ff2e93 Accent color, buttons, active states, shadows, borders
Ink Black #0a0a0a Primary text, borders, background overlays, headers
White #ffffff Primary background, card backgrounds, text backgrounds
Light Gray #f9f9f9 Subtle backgrounds, section dividers, hover states

Border & Shadow System

Component Border Shadow Hover Shadow
Section Headers 3px solid pink None N/A
Product Cards 2px solid black 4px 4px 0 pink 6px 6px 0 pink
Buttons 2px solid black 4px 4px 0 pink 6px 6px 0 pink
Chat Panel 2px solid black 8px 8px 0 pink N/A
Chat Launcher None (circle) 4px 4px 0 black 6px 6px 0 black

Verification Points

  • Primary pink (#ff2e93) applied consistently to all accent elements
  • Ink black (#0a0a0a) used for all body text and borders
  • White backgrounds for primary content areas and cards
  • Light gray backgrounds for subtle sections and hover states
  • All card borders are exactly 2px solid black
  • All card shadows are 4px offset in pink (4px 4px 0 #ff2e93)
  • All hover shadows are 6px offset (6px 6px 0 #ff2e93)
  • Section headers use 3px solid pink borders
  • Chat panel uses 8px offset shadow for visual prominence
  • Emoji rain animation contains exactly 80 unique clothing emojis
  • Emojis scale responsively (24px desktop, 16px mobile)
  • All borders use 0 border-radius (sharp corners, no rounding)
  • No gradients or blur effects in shadow system

Backend Performance & Concurrency

Reported (Not Measured)
The Campus Customs backend is built with FastAPI and implements asynchronous request handling to ensure non-blocking operation. When an AI chat request is processing (typically 5–8 seconds), other API endpoints remain responsive to concurrent requests. Note: The timings and performance claims below are referenced from earlier design documentation and have not been re-measured in this test run.

Response Times

Endpoint Response Time Concurrency Impact Status
/health (System Health) ~40ms No degradation during chat processing Reported
/api/products (Product List) ~4ms No degradation during chat processing Reported
/api/chat/message (AI Response) ~5–8s (async) Processed asynchronously; no blocking Reported

Performance Specification Points

  • Health check endpoint designed to respond under 50ms
  • Product API endpoint designed to respond under 10ms
  • Chat requests processed asynchronously without blocking event loop
  • Multiple concurrent chat requests queue properly and process in order
  • Architecture supports non-blocking async/await handling
  • Supports concurrent request loads without connection pool exhaustion
